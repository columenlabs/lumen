# Base parts

These are [shadcn/ui](https://ui.shadcn.com/docs/components) components, kept in `@columenlabs/lumen-ui/ui/*` and styled by Lumen's theme. Their props and behaviour are shadcn/ui's, so its docs are the reference for each one. Import them from Lumen, never from your own copy, so they share the theme and the shell's state:

```tsx
import { Button } from '@columenlabs/lumen-ui/ui/button';
```

The Gallery page shows the common ones in Lumen's theme; Button and Badge have their own pages with props.
